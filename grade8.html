🎮 Grade 8 – GDevelop 5

Create Your First Game: Catch the Coin

Learning Goal: By the end of this lesson you will have a playable game where a character moves with the arrow keys, collects coins, and shows a live score. You will understand objects, behaviors, variables, and events — the core of GDevelop.
Important – Use the Desktop App only
You must use the GDevelop desktop application that is already installed on your computer.
Do not use the online web editor (editor.gdevelop.io) for this lesson.

📦 Free Assets (download these first)

Before you start, download free game images. All of these are completely free and legal to use (CC0 / public domain).

Recommended (easiest for beginners):

  • Kenney.nl – Free Game Assets (best choice)
    Official site: https://kenney.nl/assets
    Look for packs such as:
    • “New Platformer Pack” or “Platformer Pack”
    • Any pack that contains characters, coins, and backgrounds
    Download → unzip the folder → keep the PNG images ready.

Other good free sources:

  • OpenGameArt.org – search “coin” or “character” (filter by CC0): https://opengameart.org
  • itch.io free assets (filter by free + CC0): https://itch.io/game-assets/free

How to use the images in GDevelop:
When you create a Sprite → click “Add an animation” → choose “Browse” or “Select image from your computer” and pick the PNG file you downloaded.

📺 Watch this first (optional but helpful)

A short overview of making a simple collectible game in GDevelop. Then follow the written steps carefully.

If the video does not load, just follow the steps below — they are complete on their own.

1 Open the GDevelop desktop app and create the project

  1. Open the GDevelop desktop application that is installed on your computer.
  2. On the home screen click Create a new project.
  3. Choose Empty game (not a template).
  4. Name the project CatchTheCoin.
  5. Choose a folder on your computer to save the project and click Create project.
✔ Check: You should see an empty scene. The Objects panel is usually on the right side of the screen.

2 Add a Background

  1. In the Objects panel (right side) click the + button (or “Add a new object”).
  2. Select Sprite.
  3. Name it Background.
  4. Click Add an animation → then choose an image from the assets you downloaded (or use the built-in Asset Store if available).
  5. Click Apply.
  6. Drag the Background object from the Objects panel onto the big scene area.
  7. Stretch it (pull the corners) so it fills the whole window.
Tip: You can right-click the object later and choose “Edit object” if you want to change the image.

3 Add the Player character

  1. Click + again → choose Sprite.
  2. Name it Player.
  3. Add an animation and select a character image from the assets you downloaded (look for a person, hero, robot, etc.).
  4. Click Apply.
  5. Drag the Player onto the scene, somewhere in the lower or middle area.
Tip: Make the player a reasonable size — not tiny and not covering the whole screen. You can resize it by dragging the corners.

4 Make the Player move (Top-Down Movement)

  1. Double-click the Player object in the Objects panel (or right-click → Edit object).
  2. Go to the Behaviors tab.
  3. Click Add a behavior.
  4. Search for or select Top-down movement (4 or 8 directions).
  5. Leave the default settings for now (Default controls = arrow keys, diagonals allowed). You can lower Max speed later if it feels too fast.
  6. Click Apply.
  7. Click the green Preview button (▶) at the top.
  8. Use the arrow keys on your keyboard. The player should move smoothly!
Common mistake: If nothing moves, make sure you added the behavior to the Player object (not the Background) and that you clicked Apply.

5 Add a Coin

  1. Create another Sprite object named Coin.
  2. Choose a coin / gem / star image from the assets you downloaded.
  3. Drag one Coin instance onto the scene, away from the Player.
Later: You can hold Ctrl (or Cmd on Mac) and drag a coin to quickly duplicate more of them.

6 Create the Score text and variable

  1. Click + → choose Text object.
  2. Name it ScoreText.
  3. In the text properties set the initial text to: Score: 0
  4. Make the font size bigger (e.g. 40–60) and choose a clear color so it is easy to read.
  5. Click Apply and place the text near the top of the scene (or top-left).

Create the Score variable:

  1. In the scene editor, open the Scene properties or use the Project manager to find Scene variables.
  2. Add a new variable:
    • Name: Score
    • Type: Number
    • Initial value: 0
✔ Check: You now have a text object that says “Score: 0” and a scene variable called Score that starts at 0.

7 Add the collection events

  1. Click the Events tab (next to the Scene tab).
  2. Click Add a new empty event (or the + button for events).
  3. Condition (left side):
    • Click “Add condition”.
    • Choose Collision → “Collision” (or search “collision”).
    • First object: Player
    • Second object: Coin
    • Click OK / Apply.
  4. Actions (right side) — add these three actions one after another in the same event:
    1. Delete an object → select Coin (this removes only the coin that was touched).
    2. Change the number of a scene variable (or “Value of a scene variable”):
      • Variable: Score
      • Modification: + (add)
      • Value: 1
    3. Modify the text of ScoreText:
      • Modification: = (set to)
      • Value (expression):
      "Score: " + ToString(Variable(Score))

      Type it carefully. The quotes and the + sign are important. You can also use the expression editor to build it.

Important: All three actions must be inside the same event that has the collision condition. Do not create three separate events.

8 Test your game!

  1. Click the green Preview button (▶).
  2. Move the player with the arrow keys.
  3. Touch the coin → it should disappear and the score should become Score: 1.
If the score does not update: Double-check the expression in the text action and make sure the variable is a scene variable named exactly Score.

🚀 Extension challenges (do these if you finish early)

  • Add 10 coins (Ctrl/Cmd + drag to duplicate). Collect them all!
  • Play a sound when a coin is collected:
    • In the same collision event add the action Play a sound.
    • You can find free sound effects on Kenney.nl or OpenGameArt as well.
  • Show “You Win!” when the player has collected all coins:
    • Create another Text object named WinText with the text “You Win!”.
    • Add a new event: Condition → Number of objects → Coin is equal to 0 (or Score = 10).
    • Action: Show / change the WinText so the player sees the message.
  • Bonus: Make the player a little faster or slower by editing the Top-down movement Max speed.
